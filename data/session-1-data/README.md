# Session 1 - generated knowledge graph data

These files are **generated**. Do not edit them by hand - rerun the scripts in
`../data-prep/` instead.

| File | Contents | Generated by |
|------|----------|--------------|
| `kg_nodes.csv` | `id`, `type` (gene / disease / icd10), `name`, `extra` | `build_kg_data.py` |
| `kg_edges.csv` | `source`, `target`, `type` (associated_with / is_a / maps_to), `weight`, `evidence` | `build_kg_data.py` |
| `kg_evidence.csv` | `source`, `target`, `datatype`, `weight`, `evidence` - the same gene-disease edges split by *kind* of evidence | `build_kg_data.py` |
| `icd10_map.csv` | MONDO id to ICD-10 code and label | `build_kg_data.py` |
| `coexpr_expression.csv.gz` | 500 patients x 737 genes of TCGA-BRCA transcriptomics | `build_coexpression_data.py` |

## The expression matrix

`coexpr_expression.csv.gz` is the transcriptomics view of the workshop's TCGA-BRCA
multi-omics bundle, subset to the genes that are **already nodes in the knowledge
graph** - 737 of 760; the other 23 are not measured. Values are log2-scale and
library-size normalised, so they can be correlated directly.

The subset exists so Part 1 can build an *inferred* co-expression network and a
*curated* knowledge graph over exactly the same genes: any difference between the
two networks is then a difference in how the edges were obtained, not in which
genes were looked at. Full-size omics work stays in Session 2 - this is 1.1 MB
against the bundle's ~900 MB.

## Sources and licences

- **Open Targets Platform** - gene entities, disease entities and ontology
  hierarchy, gene-disease association scores.
  Licensed [CC0 1.0](https://platform-docs.opentargets.org/licence) (public
  domain), so redistribution here is unrestricted.
- **MONDO Disease Ontology** - MONDO to ICD-10 cross references.
  Licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/);
  attribution is given here.

- **TCGA-BRCA** (`coexpr_expression.csv.gz`) - transcriptomics from The Cancer
  Genome Atlas, via the workshop's shared multi-omics bundle. Same cohort as
  Session 2.

Genes are keyed by **Ensembl gene ID (`ENSG...`)**, matching the identifier space
of the TCGA-BRCA transcriptomics matrix used in Session 2, so gene lists produced
by the multi-omics work can be looked up in this graph directly. Note that TCGA
carries a version suffix (`ENSG00000012048.23`) and Open Targets does not; the
suffix is stripped when the expression subset is built, and Part 3 makes
participants hit the same wall deliberately.
